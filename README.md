# Application-of-metaheuristic-algorithm-for-UAV-path-planning
This project investigates UAV path planning in three-dimensional environments using metaheuristic optimization methods, with a focus on Genetic Algorithms (GA) and Particle Swarm Optimization (PSO).

Many_waypoint file: Start from 1 chosen point, finding the shortest path that go through all points that were set up from start.
Start-End file: Finding the shortest path that go from start point to end point.
